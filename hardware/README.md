# Hardware

OVERVIEW:

Two ESP32-based builds of the remote-controlled car (`esp32-rc-car` and `esp32-remote-car`),
each pairing a microcontroller with a motor driver, steering servo, IMU, and OLED status
display. See `firmware/README.md` for the toolchain and per-project pin assignments.

## SUBFOLDERS

firmware/     device code, see firmware/README.md
pcb/          board design files, see pcb/README.md
datasheets/   component datasheets, see datasheets/README.md
bom.md        full parts list
