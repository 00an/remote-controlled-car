# 1. Record architecture decisions

## STATUS

Accepted

## CONTEXT

We need to record architectural decisions so the reasoning behind them isn't lost.

## DECISION

Use Architecture Decision Records (ADRs). One markdown file per decision in
`docs/decisions/`, numbered sequentially.

## CONSEQUENCES

Anyone browsing this folder gets a history of significant decisions and why
they were made, instead of reverse-engineering it from code or git history.
